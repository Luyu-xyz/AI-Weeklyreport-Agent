AI Weekly Report Agent (AI 自动化周报生成工作流)

📌 项目背景

在日常工作中，员工往往需要花费大量时间，将零散的、口语化的工作记录整理成结构化的周报。本项目旨在利用大语言模型（LLM）强大的语义理解与文本重构能力，打造一个“输入零散记录 -> AI 结构化处理 -> 输出标准报告”的自动化工作流，极大提升职场汇报效率。

⚙️ 核心设计逻辑


本项目完美践行了 AI 自动化工作流的四大步骤：

1. 数据输入：接收用户随口输入的口语化工作流水账。
2. AI 分析（Prompt Engineering）：通过精心设计的提示词，约束 AI 的角色扮演（资深职场导师），并强制要求其按模块分类。
3. 规则判断：AI 自动识别问题并进行术语转化（例如将“坏了”转化为“异常修复”）。
4. 执行输出：生成带格式的 Markdown 文本，直接可复制发送给领导。

🛠️ 使用工具

· 大模型：Kimi (K3 模型，擅长长文本与逻辑推理)
· 辅助开发：通义千问 / ACEModel API
· 平台：GitHub
